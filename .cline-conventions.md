## 📐 Patrones de Diseño Utilizados

### 1. Repository Pattern
```python
# Interfaz (contrato)
class IProcessRunRepository(ABC):
    @abstractmethod
    def create(self, run: ProcessRun) -> ProcessRun: ...
    
    @abstractmethod
    def get_by_id(self, run_id: str) -> Optional[ProcessRun]: ...

# Implementación SQL
class ProcessRunRepository(IProcessRunRepository):
    def __init__(self, db: Session):
        self.db = db
    
    def create(self, run: ProcessRun) -> ProcessRun:
        self.db.add(run)
        self.db.commit()
        return run
```

### 2. Strategy Pattern (para algoritmos intercambiables)
```python
class ReliabilityStrategy(ABC):
    @abstractmethod
    def calculate(self, metrics: List[ProcessMetric]) -> float:
        pass

class SuccessRateStrategy(ReliabilityStrategy):
    def calculate(self, metrics: List[ProcessMetric]) -> float:
        successful = sum(1 for m in metrics if m.status == ProcessStatus.SUCCESS)
        return (successful / len(metrics)) * 100 if metrics else 0.0
```

### 3. Observer Pattern (para eventos)
```python
class ProcessObserver:
    def __init__(self):
        self._start_callbacks: List[Callable] = []
        self._end_callbacks: List[Callable] = []
    
    def subscribe_start(self, callback: Callable) -> None:
        self._start_callbacks.append(callback)
    
    def notify_start(self, process_id: str, metadata: dict) -> None:
        for cb in self._start_callbacks:
            cb(process_id, metadata)
```

### 4. Template Method Pattern (para Robots)
```python
class BaseRobot(ABC):
    def execute(self) -> RobotResult:
        # Template method - define el esqueleto del algoritmo
        self.before_execute()
        result = self.do_execute()  # Método abstracto
        self.after_execute(result)
        return result
    
    @abstractmethod
    def do_execute(self) -> RobotResult:
        # Las subclases implementan este método
        pass
    
    def before_execute(self) -> None:
        # Hook opcional - las subclases pueden sobreescribir
        pass
```

### 5. Factory Pattern (para creación de objetos)
```python
class MetricFactory:
    @staticmethod
    def create_reliability_calculator(strategy: str = "success_rate") -> ReliabilityStrategy:
        if strategy == "success_rate":
            return SuccessRateStrategy()
        raise ValueError(f"Estrategia no soportada: {strategy}")
```

### Docstrings (Google Style)
```python
def calculate_reliability(process_id: int, days: int = 30) -> float:
    """Calcula la fiabilidad de un proceso en un período específico.
    
    La fiabilidad se calcula como el porcentaje de ejecuciones exitosas
    sobre el total de ejecuciones en el período especificado.
    
    Args:
        process_id: ID del proceso a evaluar
        days: Número de días hacia atrás para calcular (default: 30)
        
    Returns:
        Porcentaje de fiabilidad entre 0.0 y 100.0
        
    Raises:
        ProcessNotFoundError: Si el proceso con process_id no existe
        ValueError: Si days es negativo o cero
        
    Example:
        >>> reliability = calculate_reliability(1, days=7)
        >>> print(f"Fiabilidad: {reliability:.1f}%")
        Fiabilidad: 85.7%
    """
```

## 🔐 Manejo de Errores

### Jerarquía de Excepciones
```python
# backend/core/exceptions/base.py
class BaseAppException(Exception):
    """Excepción base de la aplicación."""
    def __init__(self, message: str, code: str = None):
        self.message = message
        self.code = code
        super().__init__(self.message)

# backend/core/exceptions/process_exceptions.py
class ProcessException(BaseAppException):
    """Excepciones relacionadas con procesos."""
    pass

class ProcessNotFoundError(ProcessException):
    """Proceso no encontrado."""
    def __init__(self, process_id: int):
        super().__init__(
            message=f"Proceso con ID {process_id} no encontrado",
            code="PROCESS_NOT_FOUND"
        )
```

### Uso correcto de excepciones
```python
✅ Correcto:
from core.exceptions import ProcessNotFoundError

def get_process(process_id: int) -> Process:
    process = db.query(Process).filter_by(id=process_id).first()
    if not process:
        raise ProcessNotFoundError(process_id)
    return process

❌ Incorrecto:
def get_process(process_id: int) -> Process:
    process = db.query(Process).filter_by(id=process_id).first()
    if not process:
        raise Exception("No encontré el proceso")  # Excepción genérica
    return process
```
