# 🚀 Guía de Uso - Sistema de Reglas Cline

## 📁 Archivos Creados

| Archivo                  | Propósito                                      |
| ------------------------ | ---------------------------------------------- |
| `.clinerules`            | Reglas principales del proyecto                |
| `.cline-context.md`      | Contexto completo (arquitectura, DB, patrones) |
| `.cline-instructions.md` | Plantillas por tipo de tarea                   |
| `.cline-conventions.md`  | Convenciones de código y patrones              |

---

## 🎯 Cómo Usar

### Opción 1: Carga Automática (Recomendado)
Cline cargará automáticamente el archivo `.clinerules` al iniciar.

### Opción 2: Mención Explícita
```
"Revisa .cline-context.md para entender la arquitectura"
```

### Opción 3: En el Mensaje Inicial
```
"Necesito crear un robot. Revisa .cline-context.md y .cline-conventions.md"
```

---

## 💡 Ejemplos Rápidos

### Corregir Bug
```
"El script muestra [ERR] para todos los procesos"
→ Cline sigue flujo TIPO 1 de .cline-instructions.md
```

### Nueva Funcionalidad
```
"Necesito endpoint GET /api/stats"
→ Cline sigue flujo TIPO 2 de .cline-instructions.md
```

### Crear Robot
```
"Crea robot para extraer datos de BetPlay"
→ Cline sigue flujo TIPO 7 de .cline-instructions.md
```
